# Judas Experience

Experiencia musical interactiva del proyecto **Judas** de Belentani: un hub escenico en WebGL con pipelines de analisis y extraccion de guion.

## Componentes

| Ruta | Contenido |
|---|---|
| `core/hub-scene.js` | Escena principal del hub |
| `pipelines/analyze_hub.py` | Analisis del hub |
| `pipelines/extract_script.py` | Extraccion del guion |
| `docs/superpowers/specs/` | Especificaciones de diseno (cosmos de Judas) |

## Arranque

```bash
npm install
npm run dev
```

Consulta `docs/superpowers/specs/2026-09-19-judas-cosmos-design.md` para el diseno canonico.
