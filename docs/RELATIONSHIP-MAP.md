# JUDAS RELATIONSHIP MAP

JUDAS is the narrative/music/immersive universe of the BELENTANI ecosystem.

```text
BELENTANI
   │
   ├── identity / artist / creative technology
   │
   ├── OMEGA ── system + integration
   │
   └── JUDAS
        ├── music
        ├── narrative
        ├── visual language
        ├── interaction
        └── future eras / mobile / monograph
```

## Integration

JUDAS can consume BELENTANI identity and OMEGA infrastructure while remaining an independent creative experience.

The repository is therefore a **world**, not merely a feature folder.

## Shared metadata

`ecosystem.json` is the machine-readable contract. `docs/ECOSYSTEM.md` explains the human-readable architecture.
